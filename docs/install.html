Quick install path

  1. Android: download the APK from the latest release.
  2. iOS, macOS, Windows, and Linux: download the web ZIP from the latest release.
  3. Run the checklist below and report installation or usability issues.

Android

  1. Download the APK from the latest release.
  2. Allow installs from your browser or file manager when Android asks.
  3. Open the APK and confirm the installation prompt.

macOS, Windows, and Linux

Desktop builds are available as optional artifacts, but they are not the lowest-friction install path. macOS may require Privacy & Security approval because early builds are not signed and notarized yet. Use the web bundle unless you specifically need to test desktop packaging.

Web bundle

The web ZIP contains a static Flutter web build. Serve the extracted folder through a local web server rather than opening files directly from disk. 

unzip studyos-agent-web-*.zip -d studyos-agent-web
cd studyos-agent-web
python3 -m http.server 8080

Then open http://127.0.0.1:8080.

Smoke test checklist

  1. Open the app and confirm the StudyOS login screen renders.
  2. Log in with a University of Tuebingen account if available.
  3. Complete onboarding with degree program, semester, and at least one interest.
  4. Open Chat, Schedule, Maps, Mail, and Settings from the main app.
  5. Record the first unclear step, any visible error, and one useful or missing feature.

Feedback topics

The SurveyHero form should collect platform, installation time, failed step if any, usability issues, usefulness, bugs, missing features, and concept feedback.
