Download Releases GitHub

Install a release build.

The download page points at the latest GitHub Release. Choose the artifact matching your platform and keep the checksum file next to it when you want to verify the download.

Android

  1. Download the APK from the latest release.
  2. Allow installs from your browser or file manager when Android asks.
  3. Open the APK and confirm the installation prompt.

macOS, Windows, and Linux

Download the archive for your system, extract it, and launch the app from the extracted folder. macOS may require Privacy & Security approval because early builds are not signed and notarized yet.

Web bundle

The web ZIP contains a static Flutter web build. Serve the extracted folder through a local web server rather than opening files directly from disk.
